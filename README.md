# Valynce Offline Website

Open `index.html` directly in any modern browser.

Pages:
- `index.html`
- `capabilities.html`
- `industries.html`
- `company.html`
- `contact.html`

Everything required for the visual site is included locally in `assets/`.
No web fonts, frameworks, CDNs, or external image dependencies are required.

Contact buttons open `contact.html`. The form POSTs to FormSubmit and delivers inquiries to `paul@valynceai.com`; a direct email link is also provided.

Before accepting inquiries, submit the form from the hosted website and confirm the activation email sent by FormSubmit to `paul@valynceai.com`. Delivery is not active until that confirmation is completed. FormSubmit handles CAPTCHA and the submission confirmation page. The form requires an internet connection; no private API keys are stored in this repository.
